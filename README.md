# 📚 Multi-Modal IMF RAG & Document QA System

An end-to-end Retrieval-Augmented Generation (RAG) system for question answering over complex PDF reports. The system combines PDF text extraction, table detection, OCR-based image processing, semantic embeddings, FAISS vector search, and Hugging Face FLAN-T5 to generate grounded answers with page-level source citations.

---

## 🚀 Project Overview

Analyzing complex financial and policy documents (such as IMF Article IV staff reports) requires handling structured text, numeric tables, and graphical figures simultaneously. This project provides a complete end-to-end multi-modal RAG pipeline that digests unstructured PDFs into semantic chunks, extracts embedded chart text using Optical Character Recognition (OCR), indexes the document via dense vector embeddings, and serves an interactive Streamlit web application.

Users can ask plain English questions and receive precise answers generated by `google/flan-t5-base`, fully supported by page-level citations, score relevance metrics, and collapsible data cards.

---

## ✨ Features

- **Multi-Modal Document Ingestion**: Parses standard text paragraphs, numeric data tables, and embedded images/charts.
- **OCR-Enhanced Figure Search**: Utilizes Tesseract OCR to read text inside charts, diagrams, and figures extracted from PDF pages.
- **Semantic Vector Search**: Generates 384-dimensional dense vector embeddings using `sentence-transformers/all-MiniLM-L6-v2` and indexes them using Facebook AI Similarity Search (FAISS).
- **Grounded Answer Generation**: Uses Hugging Face FLAN-T5 to synthesize answers directly from retrieved context, preventing hallucinations.
- **Page-Level Traceability & Citations**: Returns exact source page numbers, chunk types (Text, Table, Image), relevance scores, and rendered table/figure previews for every answer.
- **Interactive Streamlit Web Interface**: Features real-time PDF processing, document selection, chat history, and formatted tabular rendering.

## 🛠️ Tech Stack

- **Frontend & Web Framework**: Streamlit
- **PDF Extraction & Layout Analysis**: PyMuPDF (`fitz`), Pillow (`PIL`)
- **Optical Character Recognition (OCR)**: Tesseract OCR via `pytesseract`
- **Embedding Model**: `sentence-transformers/all-MiniLM-L6-v2`
- **Vector Database**: FAISS (`faiss-cpu`)
- **Language Model**: Hugging Face Transformers (`google/flan-t5-base`)
- **Framework Glue**: LangChain Core / Community / HuggingFace
- **Data Wrangling**: Pandas, NumPy

## 📦 Installation & Setup

### 1. System Requirement: Install Tesseract OCR

To enable image and chart OCR extraction, Tesseract OCR must be installed on your system.

- **Windows**: Download and run the installer from [UB-Mannheim Tesseract Wiki](https://github.com/UB-Mannheim/tesseract/wiki). Ensure Tesseract is added to your System PATH or set the `TESSERACT_CMD` environment variable pointing to `tesseract.exe`.
- **macOS**:
  ```bash
  brew install tesseract
  ```
- **Linux (Ubuntu/Debian)**:
  ```bash
  sudo apt-get update
  sudo apt-get install tesseract-ocr
  ```

### 2. Clone the Repository
```bash
git clone https://github.com/ShreyaRumale19/Multi-Modal-IMF-RAG-Document-QA-System.git
cd Multi-Modal-IMF-RAG-Document-QA-System
```

### 3. Create & Activate Python Virtual Environment
- **Windows (PowerShell)**:
  ```powershell
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  ```
- **macOS / Linux**:
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 4. Install Dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## ⚡ Execution Pipeline

### Option A: Automated Pipeline (Recommended)
Place your target PDF in `data/raw/qatar_test_doc.pdf` and run the master script:
```bash
python run_pipeline.py
```

### Option B: Step-by-Step Manual Processing

1. **Extract PDF Content (Text, Tables, OCR Figures)**:
   ```bash
   python process_document.py
   ```
   *Output*: Generates `data/processed/extracted_chunks.json`.

2. **Generate Vector Embeddings & Build FAISS Index**:
   ```bash
   python create_embeddings.py
   ```
   *Output*: Generates the FAISS vector index files in `data/vector_store/`.

3. **Launch Streamlit Web App**:
   ```bash
   streamlit run app.py
   ```
   Then navigate to **http://localhost:8501** in your browser.

## 🔍 Citation & Traceability System

Every generated answer is accompanied by a **"View Citations"** card containing:
1. **Source Page & Rank**: Exact page number in the original PDF document.
2. **Chunk Type**: Identifies whether the information originated from standard text paragraphs, numeric table blocks, or OCR figure extractions.
3. **Relevance Score**: Vector similarity score matching your query.
4. **Rich Content Preview**: Formats numeric tables into clean interactive grids and displays OCR-extracted chart text or rendered figure previews.
